# Role

In my role, I took on the responsibility of refactoring the codebase to enhance its structure, readability, and maintainability. Additionally, I spearheaded the migration to <Term def="A library that connects a server framework like Laravel directly to a React front end, so you can build a single-page app without a separate API.">Inertia.js</Term>, which brought server-side rendering capabilities to the React front-end within the Laravel framework.

# Results

The code refactoring and migration efforts resulted in significant improvements to the performance and user experience of ROAR. The codebase became more robust and easier to work with, leading to increased development efficiency. By integrating Inertia.js, we reduced page load times and enhanced responsiveness, ultimately benefiting the scheduling and management of education sessions for newly hired employees at VCH.
